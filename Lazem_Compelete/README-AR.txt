Lazem Browser v0.1 (متصفح لازم - النسخة الأولى)

التشغيل على ويندوز:
1) نزّل Node.js من nodejs.org وثبّته (مرة واحدة).
2) فك الضغط عن الملف، وبعدين دوس دبل كليك على: run-windows.bat
   (أول مرة بينزّل Electron، ياخد كام دقيقة).
أو من الـ terminal داخل الفولدر:  npm install  ثم  npm start

الموجود فعلًا:
- تبويبات (Ctrl+T جديد، Ctrl+W قفل، Ctrl+L الشريط)
- شريط عنوان وبحث، اختيار محرك البحث: Google / DuckDuckGo / Brave / Bing / Yahoo
- حجب إعلانات مجاني من الكود نفسه: ملف blocklist.txt (ضيف أي دومين سطر جديد) + إخفاء بعض مربعات الإعلانات. بيحجب الشائع بس، مش كل إعلان.
- صفحة تبويب جديد فيها اختصارات سريعة (Scratch, Python, YouTube, GitHub, Google) وتغيير الخلفية (لون أو رابط صورة)
- مفضلة (نجمة)، وإعداداتك بتتحفظ

لسه مش موجود: VPN، لغة الإضافات الخاصة، وضع أوفلاين، Lazem Search، دومينات لازم، Firebase.
