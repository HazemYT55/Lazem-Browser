Lazem Browser متصفح لازم · Lazem_Compelete

مهم: لازم براوزر برنامج كمبيوتر (Electron)، مش موقع بيشتغل من ملف HTML. الصفحة دي مدخل وشرح بس. الشعار مقترح وغير معتمد.
التشغيل
  1. نزّل وثبّت Node.js من nodejs.org.
  2. نزّل الفولدر ده (Lazem_Compelete) من GitHub.
  3. داخل الفولدر شغّل:
    npm install
npm start
    أو على ويندوز دبل كليك على run-windows.bat.
الموجود (متجرب على Linux فقط)
  • تبويبات وشريط عنوان وبحث، واختيار محرك البحث
  • رجوع وتقدم ومفضلة
  • حجب إعلانات مجاني (blocklist.txt)
  • صفحة تبويب جديد باختصارات تتسحب وتتجمع في فولدرات
  • خلفية بلون أو صورة
مش موجود لسه: VPN، الإضافات، وضع أوفلاين، Lazem Search، دومينات لازم، النشر، تسجيل دخول.
ملفات المشروع
  • main.js : قلب البرنامج
  • ui.html و ui.css : الشريط العلوي
  • newtab.html و newtab.css و newtab.js : صفحة التبويب الجديد
  • EDITION.md : وصف النسخة
